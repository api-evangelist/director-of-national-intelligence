# Office of the Director of National Intelligence (ODNI)

> ODNI leads intelligence integration across the United States Intelligence Community. It publishes no
> developer program and no API documentation, but its public website at www.odni.gov runs on WordPress
> and serves an anonymous, read-only REST API over its newsroom, its site pages and its catalog of
> published documents. This file was GENERATED by API Evangelist on 2026-09-06 from the artifacts in
> this repository; ODNI does not publish an llms.txt (https://www.odni.gov/llms.txt returns 302 to the
> homepage).

## Read this first — how to actually call it

- The canonical WordPress base `https://www.odni.gov/wp-json/` and every path beneath it return HTTP 301
  to `https://www.odni.gov/`, which then returns 200 and 187KB of HTML. A client that does not check the
  content type will parse a web page as JSON.
- Use the query-string route form instead: `https://www.odni.gov/?rest_route=/wp/v2/posts&per_page=3`
- Use a plain User-Agent. The Akamai edge answers HTTP 403 to browser-shaped User-Agent strings and
  serves plain clients normally.
- No credential is required. No signup, no API key, no OAuth, no plans.
- The `_links` on every record point at the blocked `/wp-json/` base; rewrite them before following.

## What is NOT here

- No intelligence holdings, reporting or classified material. This is a public-affairs content API.
- No OpenAPI, MCP server, agent card, security.txt, apis.json, llms.txt, status page, changelog, SDK,
  CLI, sandbox or pricing published by ODNI. Each was probed; see well-known/ for the recorded statuses.
- No live copy of ODNI's own IC technical specifications (ISM.XML, NTK.XML, IC-ID.XML, IC-SF.XML,
  IC-Docbook.XML, ISMCAT, IC-GENC). Those pages were removed in the site rebuild and now soft-404 —
  every legacy `/index.php/who-we-are/organizations/ic-cio/ic-technical-specifications/...` URL returns
  HTTP 200 serving the ODNI "About" page. Do not treat those URLs as live.
